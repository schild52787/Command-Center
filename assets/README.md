# Assets Directory

This directory should contain the app icons and splash screens.

## Required Files

The following files are referenced in `app.json` but are optional for development:

- `icon.png` - App icon (1024x1024 px)
- `splash.png` - Splash screen (1284x2778 px)
- `adaptive-icon.png` - Android adaptive icon (1024x1024 px)
- `favicon.png` - Web favicon (48x48 px)

## Using the App Without Icons

The app will work perfectly fine in Expo Go without these assets. They're only needed when you want to:
- Build a standalone app
- Customize the app appearance in Expo Go
- Submit to the App Store

## Creating Custom Icons

If you want to add custom icons later:

1. **Easy Way**: Use an online icon generator like:
   - https://www.appicon.co/
   - https://icon.kitchen/

2. **Manual Way**: Create PNG images with the dimensions listed above

3. **AI-Generated**: Ask an AI image generator to create a cute morning routine themed icon with:
   - Bright, cheerful colors (pink, yellow, blue)
   - Morning symbols (sun, alarm clock, star)
   - Child-friendly style

## Current Status

For now, the app uses Expo's default icons, which is perfectly fine for testing and development!
