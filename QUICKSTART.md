# Quick Start Guide - Get Elle's App Running in 5 Minutes! ⚡

## Step 1: Install Expo Go on iPad (2 minutes)

1. Open the **App Store** on your iPad
2. Search for **"Expo Go"**
3. Download and install it (it's free!)
4. Keep the app handy - you'll need it in a moment

## Step 2: Install Dependencies (1 minute)

Open your terminal on your computer and run:

```bash
cd /home/user/Command-Center
npm install
```

This will download all the necessary packages. Grab a coffee while it installs!

## Step 3: Start the App (30 seconds)

In the same terminal, run:

```bash
npm start
```

You'll see a QR code appear in your terminal!

## Step 4: Connect Your iPad (1 minute)

1. Make sure your iPad and computer are on the **same WiFi network**
2. Open **Expo Go** on your iPad
3. Tap **"Scan QR code"**
4. Point your iPad camera at the QR code in your terminal
5. Wait a few seconds for the app to load

## Step 5: Let Elle Try It! 🌟

The app is now running on your iPad! Elle can:
- Press the big green **START** button
- Watch the timer count down
- See her progress through each morning task
- Get a celebration when she's done!

## Parent Settings

Tap the **⚙️ gear icon** in the top-left to:
- Adjust the time for any segment
- Reset to default timings
- See the total routine time

## Troubleshooting

**Can't see the QR code?**
- Press `w` in the terminal to open in a web browser
- Or manually type the URL shown in Expo Go

**iPad won't connect?**
- Double-check you're on the same WiFi network
- Try restarting the Expo server: press `r` in the terminal

**App crashes or won't load?**
- Close Expo Go completely and reopen it
- Restart the server with `npm start`

## Making Changes

Any time you want to adjust the app:
1. Open the settings (gear icon)
2. Tap the + or - buttons to change segment times
3. Tap "Save Changes"
4. Done! The new timings are saved automatically
